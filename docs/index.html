How subscribing works

These links add a live subscription, not a one-time import — your calendar app re-checks the URL periodically, so you'll see updates automatically. In Google Calendar, use "Other calendars" → "From URL" and paste the raw .ics link. In Apple Calendar, use File → "New Calendar Subscription", or just click "Subscribe" above.
